# 전체 노트 (날짜순)

모든 Tech 노트를 최신순으로 나열한 페이지입니다. 목록 자체는 Quartz가 빌드 시 생성하므로 이 파일에는 담기지 않습니다 — 공개 사이트에서 보세요.

- 정렬·표시 기준: frontmatter `created`(작성일). Quartz 설정의 `defaultDateType` 이 정하며 현재 값은 `created` 입니다.
- `created` 가 없으면 git 커밋 날짜, 그것도 없으면 파일 생성 시각으로 떨어집니다(`CreatedModifiedDate` 의 `priority`). 노트에는 항상 `created` 를 적어 두세요.
- 폴더 단위로 보려면 [[index|도메인 목록]]에서 각 MOC로 들어가면 됩니다. 폴더 페이지도 날짜순입니다.
