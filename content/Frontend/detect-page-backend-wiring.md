# 프론트 페이지가 실데이터에 연동됐는지 판별

> Vue/Nuxt 페이지가 "목업(하드코딩)"인지 "실백엔드 연동"인지 빠르게 가리는 법.

## 함정
`rg "/api|useFetch|\$fetch"` 로만 판단하면 **틀린다**. 많은 앱이 API 호출을 **service layer**(`~/services/xxxService.js`의 `getFooApi()` 등)로 감싸므로, 페이지 코드에는 `/api` 문자열이 안 보인다. 그런데도 실제로는 서비스 함수를 통해 백엔드를 친다. (이걸 놓치면 "이 화면은 목업/백엔드 없음"이라 오판한다.)

## 올바른 판별
1. 페이지 **import**를 본다: `from '~/services/...'` 또는 `from '~/stores/...'` 있으면 실연동 가능성 높음.
2. 데이터가 `ref([])`로 비었다가 `onMounted`에서 서비스 함수로 채워지면 → 실데이터.
3. 반대로 상단에 `const rows = [ {…하드코딩…} ]` 배열이면 → 목업.
4. 확신하려면 서비스 함수 본문까지 따라가 실제 엔드포인트/`$fetch`를 확인.

## 교훈
- **"백엔드 코드가 있냐"** 와 **"이 페이지가 거기 연동됐냐"** 는 별개 질문이다. 프론트 grep 하나로 백엔드 유무를 단정하지 말 것.
- 근거는 항상 import → 서비스 계층 → 엔드포인트까지 따라가 확인한다.
