# 터미널 마우스 트래킹 누수

> **TL;DR**: TUI 앱이 마우스 트래킹 모드를 끄지 않고 죽으면 트랙패드/스크롤 입력이 쉘 프롬프트에 이스케이프 문자로 쏟아진다. `reset` 한 방이면 복구된다.

---

## 개요

- **무엇인가**: vim·htop·tmux 같은 TUI가 활성화한 xterm 마우스 리포팅 모드(1000/1002/1003 등)가 비정상 종료로 잔류하는 현상
- **증상**: 터미널(WezTerm 등)에서 트랙패드만 움직여도 `[<35;12;40M` 같은 문자가 zsh 입력줄에 들어옴

---

## 해결

```bash
reset          # 터미널 상태 전체 초기화 (가장 간단)
```

또는 마우스 모드만 끄기:

```bash
printf '\e[?1000l\e[?1002l\e[?1003l\e[?1006l\e[?1015l'
```

| 모드 | 의미 |
|---|---|
| 1000 | 클릭 리포팅 |
| 1002 | 드래그 리포팅 |
| 1003 | 모든 이동 리포팅 (누수 시 제일 시끄러움) |
| 1006/1015 | 좌표 인코딩 확장 |
