# 모델 드리프트 (Model Drift)

> **TL;DR**: 배포 후 실제 데이터가 학습 데이터와 달라지면서 모델 성능이 떨어지는 현상 — PSI/KS로 감지

---

## 개념

ML 모델은 과거 데이터로 학습됨. 시간이 지나면 현실 데이터 분포가 바뀌어 예측 정확도 하락.

```
학습 시점: 사용자 패턴 A
6개월 후:  사용자 패턴 B (계절, 트렌드 변화)
→ 모델이 B를 잘 못 맞춤 = 드리프트
```

---

## 드리프트 종류

| 종류 | 설명 |
|---|---|
| Data drift | 입력 데이터 분포 변화 |
| Concept drift | 입력-출력 관계 자체가 변화 |
| Label drift | 정답 레이블 분포 변화 |

---

## 감지 지표

### PSI (Population Stability Index)

학습 데이터와 현재 데이터의 분포 차이를 수치화.

| PSI 값 | 해석 |
|---|---|
| < 0.1 | 안정적 |
| 0.1 ~ 0.2 | 약간 변화, 모니터링 필요 |
| > 0.2 | 유의미한 드리프트, 재학습 고려 |

### KS (Kolmogorov-Smirnov) Test

두 분포가 통계적으로 같은지 검정. p-value가 낮으면 분포가 다름.

---

## 대응

```
드리프트 감지
  → 알림 발송
  → 원인 분석 (데이터 수집 문제? 실제 패턴 변화?)
  → 새 데이터로 모델 재학습
  → 재배포
```
