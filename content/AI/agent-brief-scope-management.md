# 작업 커서(agent brief) 비대 방지

> **TL;DR**: 작업 커서(agent brief)는 작업일지·지식 저장소가 아니다. 다음 세션이 바로 행동하기 위한 현재 상태만 남기고, 나머지는 정보 수명에 맞는 저장소로 옮긴다.

---

## 개요

- **무엇**: agent brief(작업 커서) 문서의 크기·수명 관리 원칙
- **왜 / 언제**: 커서 문서가 완료 서술로 비대해져 새 세션이 오래된 내용을 다시 추론하는 비용이 커질 때

## 원칙

- 완료 항목은 상세 서술 대신 커밋 해시와 결과 한 줄로 압축한다.
- 반복 참조할 운영 지식은 structure map이나 Tech 노트로 옮긴다.
- backlog와 현재 커서를 같은 문서에 중복 기록하지 않는다.
- 문서 크기 상한을 CI/drift 검사에 넣고, 초과 시 세션당 한 번 경고한다.
- `base_head`, 현재 작업, 검증된 사실, blocker, 다음 행동만 유지한다.

크기 제한은 그 자체가 목표가 아니라 "새 세션이 오래된 완료 서술을 다시 추론하는 비용"을 제한하는 장치다. 제한을 넘으면 문장을 줄이는 데 그치지 말고 정보의 수명에 맞는 저장소로 이동한다.
