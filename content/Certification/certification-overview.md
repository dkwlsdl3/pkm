# 자격증 개요 (MOC)

> 시스템·스토리지 엔지니어링 학습 경로를 강제해주는 자격증 로드맵

---

## 용어

| 표기 | 원어 | 뜻 |
|---|---|---|
| LFCS | Linux Foundation Certified System Administrator | Linux Foundation의 시스템 관리자 자격. 배포판 중립 |
| RHCSA | Red Hat Certified System Administrator | Red Hat 계열 시스템 관리 기초 자격. 실기 시험 |
| RHCE | Red Hat Certified Engineer | RHCSA 상위 자격. 현재는 Ansible 자동화 중심 |
| CKA | Certified Kubernetes Administrator | CNCF의 Kubernetes 관리자 자격 |
| Linux+ | — | CompTIA의 Linux 자격 |
