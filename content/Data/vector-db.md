# Vector DB (벡터 데이터베이스)

> **TL;DR**: LLM·생성형 AI 서비스에 필수적인 데이터베이스

---

## 개념

- AI 모델이 데이터를 인식하는 방식인 **벡터(숫자 배열)** 형태로 저장·검색하는 DB
- "의미적으로 비슷한 것"을 찾는 **유사도 검색**에 특화

## 왜 필요한가?

- LLM은 텍스트를 벡터로 변환해서 처리함
- RAG(검색 증강 생성) 구현 시 외부 문서를 벡터로 저장해두고 유사한 내용을 검색해 LLM에 컨텍스트로 제공

## 주요 제품

| 제품 | 특징 |
|------|------|
| **Pinecone** | 완전 관리형 클라우드 서비스, 쉬운 시작 |
| **Milvus** | 오픈소스, 대규모 처리에 강함 |
| **pgvector** | PostgreSQL 확장, 기존 RDB에 벡터 기능 추가 |
