# 워크플로우 오케스트레이션

> **TL;DR**: 데이터 파이프라인의 스케줄링 및 실행 순서를 관리하는 도구

---

## Apache Airflow

- 파이프라인 스케줄링의 전통적 강자
- Python으로 DAG(방향성 비순환 그래프)를 작성해 작업 흐름 정의
- 오래된 만큼 레퍼런스가 많지만, 설정이 복잡하고 무거움

## Dagster

- 데이터 자산(Asset) 중심의 차세대 오케스트레이터
- "어떤 데이터가 언제 만들어졌는가"를 추적하는 데 강점
- 개발자 경험(DX) 우수, 타입 안정성 지원

## Prefect

- Airflow의 복잡함을 개선한 차세대 스케줄러
- Python 코드를 최소한으로 수정해서 파이프라인화 가능
- 클라우드 UI가 직관적

## 선택 기준

| 상황 | 추천 |
|------|------|
| 레거시 시스템 연동, 레퍼런스 중요 | Airflow |
| 데이터 품질·계보 추적 중요 | Dagster |
| 빠른 시작, 간단한 구성 | Prefect |
