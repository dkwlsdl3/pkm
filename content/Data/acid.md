# ACID

> **TL;DR**: 데이터베이스 트랜잭션의 안전을 보장하는 4가지 원칙

---

- **A (Atomicity - 원자성):** 전부 성공하든지 아예 취소되든지. 중간 상태 없음. (예: 계좌이체 시 내 돈만 빠지는 상황 방지)
- **C (Consistency - 일관성):** DB가 정한 규칙을 항상 만족해야 함. (예: 나이 칸에 문자 입력 불가)
- **I (Isolation - 고립성):** 동시에 여러 사람이 수정해도 서로 간섭 없이 순서대로 안전하게 처리.
- **D (Durability - 지속성):** 한 번 저장된 데이터는 서버 장애가 나도 사라지지 않음.
