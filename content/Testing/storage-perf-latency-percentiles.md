# 스토리지 레이턴시 백분위수 읽기 (avg/p95/p99/CoV)

> **TL;DR**: 평균만 보면 꼬리 지연을 놓친다 — avg → p95 → p99 → p99.9 → max 순으로 읽고, CoV 급등은 조건 오염부터 의심한다.

---

## 레이턴시 읽는 순서

- avg → p95 → p99 → p99.9 → **max** 순으로 확인한다. 평균은 문제를 숨긴다.
  - 예: 999회 1ms + 1회 235초 → 평균은 괜찮아 보여도 사용자 1명은 235초 hang
  - **avg > p99 역전** = 단발성 극단 이상치 신호 (max만 봐선 놓침)

## CoV (변동계수)

- CoV = 표준편차/평균. 반복 측정 간 흔들림 정도를 나타낸다.
- 측정 조건이 작거나 캐시/drop 타이밍이 과격해도 CoV가 커질 수 있음 → CoV만으로 "불안정"이라 단정하지 않는다.
